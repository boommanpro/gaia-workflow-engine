# 产物面板画布：交互修复与紧凑重排（2026-11-04）

## 问题

chat 会话页右侧产物面板（`ai-workspace/artifact/LightCanvas.tsx`，纯 SVG 自绘轻量预览）
用户实测三个问题：

1. **放大漂移**：`setPan` 嵌在 `setZoom` updater 内（违反 updater 纯函数约定），
   `React.StrictMode` 下 updater 双调用 → 每次 wheel 的 pan 补偿叠加两次而 zoom 只乘一次，
   离光标越远漂得越多；且 viewBox 随每个 document 事件重算（fit 布局框），AI 流式新增
   节点时坐标系整体变化、pan/zoom 存的是旧坐标系值 → 视口跳变。
2. **缩放太快**：wheel 只取 `deltaY` 符号、每事件固定 ×1.2 大步长，触控板一次惯性
   手势几十个事件瞬间顶到上限；无任何平滑。
3. **节点太稀**：168×52 大卡 + 后端 ELK 稀疏坐标（按 360px 宽编辑器节点留距），
   图 2554×1168（2.2:1 宽扁）对 418×~780（1:1.9 竖长）面板 → fit 被宽度约束
   k=0.164，节点显示仅 27×8.5px，垂直方向 76% 面板空间空转；连线为灰色实心
   三角箭头，与 /editor 编辑器（靛蓝 #4d53e8、V 形箭头）风格割裂。

## 行业对标（2026-11-03/04 核查）

- **手势**：d3-zoom `wheelDelta` 默认按 deltaY 幅度连续缩放
  （像素模式 ×0.002、ctrl×10）；触控板捏合被浏览器合成带 `ctrlKey` 的 wheel 事件
  （Chrome/FF/Safari 事实标准，deltaY≈0.5~3）；Figma/Miro/tldraw/Excalidraw 与
  React Flow design-tool 配置均为「普通滚轮=平移，⌘/Ctrl+滚轮与捏合=缩放」；
  程序化缩放（按钮/fitView）带 200-250ms ease-out，滚轮跟手不动画（避免叠加「飘」感）。
- **密度**：fit-all 下节点显示尺寸 = 节点宽 × min(面板宽/图宽, 面板高/图高)——
  等比缩小节点与间距不改变显示尺寸（图等比缩），关键是让图纵横比逼近面板形状；
  n8n 缩略图 / React Flow minimap 均为「只取结构、自定几何」的独立排版。

## 决策（用户确认三项方向：Figma 式手势 / 优化贝塞尔 / 靛蓝统一）

- **视口**：`zoom`/`pan` 合并单一 `view` state 原子更新（StrictMode 安全）；锚定
  缩放公式 `pan' = p − (p − pan) × k'/k` 不变；**viewBox 冻结机制**——用户一旦
  缩放/平移即冻结布局框，流式重算不再晃动视口，「适应画布」/双击解冻复位。
- **手势**：普通滚轮/两指滚动=平移（滚动语义、方向对齐 /editor 的 d3 相机）；
  ⌘/Ctrl+滚轮与捏合=光标锚定缩放，`factor = exp(−clamp(Δ,±10)×0.01)`（触控板
  细腻 ×1.02/事件，鼠标滚轮一格约 ×1.1）；±按钮 180ms ease-out 补间（rAF 为主、
  节流兜底强制终态）；`ZOOM_MAX` 4→8（fit 基准下面板小，4× 时文字仍不可读）。
- **连线**：控制点 d3 linkHorizontal 风格 `d=clamp(dx/2, 24, 96)` 水平伸出（大纵向
  跨度不中点陡坠）；同源多出边/同汇多入边双端对称扇形错位；V 形开放箭头；颜色
  引用 `--g-workflow-line-color-default`（与编辑器共用一个 CSS 变量，单一来源）。
- **紧凑重排**：不复用后端坐标，只取其结构——按 x 聚类成列（ELK 同列 x 严格对齐，
  容差 84）、列内按 y 序围绕垂直中心对称堆叠（主干居中一线、分支上下展开）、
  列横向等距；节点渲染为 120×30 单行徽章（类型色点 + 标题 9px）；流式无坐标
  节点挂入边源的下一列。

## 效果（本会话 9 节点 / 7 列实测）

| 指标 | 改前 | 改后 |
|---|---|---|
| 图尺寸 | 2554×1168 | 1112×174 |
| fit 比例 | 0.164 | 0.376 |
| 节点显示宽度 | 27.5px | 45px（可辨面积 ~2.7×） |
| 捏合锚点漂移 | 明显（StrictMode 双补偿） | 0.00px（6 次捏合实测） |
| 列形态 | 后端稀疏坐标 | 严格等距，分支垂直对称 |

验证：console eslint 0 问题；tsc 改动文件 0 错误（全仓 29 个为存量基线）；
vitest 全量通过（187 用例）；浏览器合成事件实测手势语义/锚点/几何断言。
未验证：真实触控板手感（合成 WheelEvent 语义一致但不还原惯性）；深链工作流
（10+ 列）fit 仍受宽度约束，后续可考虑蛇形换行布局。

边界：预览布局与 /editor 坐标解耦（列结构/层内序/拓扑保持，几何自定）——预览
表达「有哪些节点、怎么连」，编辑器仍是精确布局唯一事实源（P-02/P-07）。
