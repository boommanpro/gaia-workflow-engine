# 节点目录首批实施记录

日期：2026-10-24。总体设计已获批准，本记录仅覆盖首批目录基础设施，不代表 P0–P5 全部完成。

## 已实施

- 后端资源 node-catalog/index.json 定义 16 类节点的版本、能力、Schema 路径及默认数据关联。
- defaults.json 提供 12 类可生成节点的共享默认数据，前端直接导入同一资源，不复制参数 Schema。
- NodeCatalog 加载并检查目录，NodeSchemaRegistry 复用目录加载契约；启动组件检查资源，缺失或无效时失败。
- 后端生成白名单、工具描述和前端生成清单由 aiCreatable 能力派生。
- AI knowledge 在说明文档缺失时仍可返回契约、默认值、版本及能力。
- code/condition 的画布创建接入共享默认值，保留节点 ID 和标题行为。
- 前端未知类型明确拒绝，默认值深拷贝，覆盖数组采用整体替换，节点创建不再隐式转换扁平字段。
- HTTP 规范化保留规范 body/timeout，支持重复处理而不丢失数据。
- 从默认模板移除硬编码凭证；历史凭证仍应由所有者撤销或轮换。
