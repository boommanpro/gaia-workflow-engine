## 会话模型前提（断言依据，沿用第一轮）

1. 会话 = 草稿空间；applyWorkflow 走确认门禁（require）；一次用户消息 = 一条流式回复
2. 右栏版本切换器两轴：本会话版本 + 落版版本
3. 新增：assistant 消息持久化 thinking；run 结束后 debug_data 出现调用日志条目

## 执行纪律

- 每用例新起会话（注明「接 TCxx」除外）；确认卡 60s 内点击
- **一次成功率统计**：记录每个用例首个工具调用是否直接成功（关注点 1 的量化）
- IAB 长交互失效预防：每用例前 `visibility.set(true)` + 必要时重建标签页；点击统一 evaluate 几何 + 坐标点击
- Qwen 单轮 20~40s，等待上限 5 分钟；确认卡 300s 超时自动拒绝
- 发现 bug：最小复现 → 定位 → 修复 → 重编译重启 → 重跑该用例
