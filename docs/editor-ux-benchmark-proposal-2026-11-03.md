### 2.3 值得吸收的实践（按价值排序，v2 合并更新）

1. 左下工具簇 + 一键自动布局（Dify/Coze/Make 收敛模式）

9. 运行态上节点（Coze 绿边、影刀逐行绿勾、千帆节点下方结果）
10. **Zapier AI 提示条**（画布顶部自然语言生成工作流——对接现有 AI 会话/草稿同步链路）

## 4. 四套整体方案

### 方案一 · 轻画布（Light Canvas）

**主张**：工具全部浮层化，画布是唯一主角；节点自带内联表单。对标 Coze/Dify 的收敛形态，也是现底座的最小演进。

| 维度 | 设计 |
|---|---|
| 工具栏 | 左下三段浮簇：**视图**（缩放%/适应/小地图/交互模式）· **编辑**（撤销/重做/自动布局/连线/批注）· **插入**（主色「+添加节点」）；「···」溢出收开发者工具（报告/DSL/导出/只读）+ 快捷键帮助 |
| 节点 | 图标芯片 + 标题 + 副标题摘要 + 状态徽标；悬停快捷操作（复制/禁用/删除）；菜单增强（重命名/副本 ⌘D/试运行此节点/查看 JSON）；全局紧凑模式 |
| 分组 | 彩色组框（标题+描述+节点数）+ 折叠胶囊 + 便签；折叠态存本机 |
| 图标 | 24px 线性 SVG + 分类色芯片，注册表单源（见页签「节点图标」） |
| 主题 | 齿轮偏好面板：背景/连线/强调色/紧凑；深色模式随应用（见页签「主题与设置」） |

底座适配：全部基于现有 free-layout 插件与 demo 组件改造，不动 DSL。成本：**低-中**。

### 方案二 · 调试台（Debug Studio）

**主张**：把工作流当程序调试——影刀/UiPath 范式。结构感、确定性、逐行可验证优先于自由度。

| 维度 | 设计 |
|---|---|
| 布局 | **三栏工作台**：左「指令面板」（搜索 + 分类 + 收藏，拖拽/双击插入）；中画布（保留 free 2D，叠加**行号沟槽**与断点位）；右「结构面板」= 子流程/全局变量/资源 + AI 助手入口（非属性面板）；**底部停靠**：运行日志 / 错误列表 / 调试变量（暂停时出现） |
| 工具栏 | **顶部**：保存 · 撤销/重做 · 折叠为组 · 自动布局 ▎ **▶ 运行 · ⏭ 单步 · ● 断点模式 · ■ 停止** ▎ 帮助 |
| 节点 | 指令卡：行号 + 芯片 + 标题 + 参数摘要 chips + 内联展开参数 + 执行后**绿勾**；每卡「▶ 运行此指令」微运行（现有单节点试运行显性化）；loop/condition = 嵌套容器（现有 free-container 演进） |
| 分组 | 「折叠」组：命名、**可嵌套**、批选折叠（影刀模式；现有 group 增强） |
| 图标/主题 | 同方案一（共用组件细节） |

底座适配：布局高；断点/单步/变量监视需执行器配合（暂停语义、步进 API）→ **契约评审项**。行号沟槽、绿勾、停靠面板为纯前端。成本：**中-高**。与本项目「规则引擎 + 试运行 + 运行历史」基因最契合。

### 方案三 · 线性链（Linear Flow）

**主张**：Zapier/千帆范式——阅读顺序即执行顺序。单轴左→右步骤链，分支是可折叠「路径组」，配置进右栏，画布顶部一条 AI 提示条。

| 维度 | 设计 |
|---|---|
| 布局 | 顶栏：标题 + 草稿/已发布标签 + Fit + **审阅变更** + 折叠路径 + 导出 PNG + 发布；画布顶部 **AI 提示条**（「描述你想构建的工作流…」→ 对接现有 AI 会话/草稿同步）；右侧步骤配置面板；**底部常用节点条**（固定常用 + 搜索，拖入即插） |
| 节点 | 横向步骤卡：芯片 + 标题 + 一句话摘要 + 状态；点击 → 右栏配置（Setup/Test 两态） |
| 分组 | 路径组（Paths）折叠/展开为胶囊；无自由分组 |
| 图标/主题 | 同方案一 |

底座适配：**低**——free-layout 天生自由摆放，需引入 FlowGram **fixed-layout** 编辑器或自建强约束层；画布 DSL 布局语义变化大。成本：**高**。适合作为面向新手的「简模式」储备，或由 AI 工作区轻画布承担类似角色。

### 方案四 · 自由工作区（Free Studio）

**主张**：n8n/Make 范式——chrome 极简，操作跟随选中对象出现；工具条服务「运行与版本」而非视图。

| 维度 | 设计 |
|---|---|
| 工具栏 | **无常驻画布工具栏**；**底部工具条**（Make 式）：▶ 试运行一次 · 保存版本 · 启用开关 · 便签面板 · **选区级对齐** · 搜索替换 · 版本历史；**右下缩放簇**（＋/−/适应）；撤销/重做并入底部条 |
| 节点 | 悬停快捷操作（play/禁用/删除，n8n 式）；状态徽标；紧凑模式 |
| 分组 | 框选即现**浮动工具条**（建组 ⌘G/复制/对齐/删除）；组 + 丰富便签 + **全局便签面板**（聚合所有批注，Make 式）；数据流动画（Explain flow，运行回放时连线流光） |
| 图标/主题 | 同方案一 |

底座适配：中-高——浮动工具条已有 `SelectorBoxPopover` 基础；选区级对齐需给自动布局加 selection 过滤（小改）；流光动画用现有连线 flowing 态。成本：**中**。

### 4.6 已确认方向：设置驱动（2026-11-04）

在方案一基线上，把「布局形态之争」转化为「用户偏好」：编辑器头部齿轮偏好面板扩展为三段式（外观 / 工作区 / 节点添加），全部持久化到 `gaia.editor.*`（localStorage，不进工作流 JSON）：

| 设置组 | 设置项 | 取值 | 默认 | 实现要点 |
|---|---|---|---|---|
| 外观 | 主题模式 | 跟随应用 / 浅色 / 深色 | 跟随应用 | 复用 `gaia.themeMode` + `--g-*` token |
| 外观 | 画布背景 | 点阵 / 网格 / 无 | 点阵 | FlowGram background 插件参数 |
| 外观 | 连线样式 | 贝塞尔 / 折线 | 贝塞尔 | 现有 `switchLineType` + 记忆 |
| 外观 | 强调色 | 紫 / 蓝 / 青 / 洋红 | 紫 `#4d53e8` | 写入 `--g-workflow-line/port-color-*` 派生 |
| 工作区 | **工具栏位置** | **下部居中** / 左下 / 顶部 / 左侧竖排 | **下部居中** | 工具栏组件 `position` prop 化；小地图固定左下 |
| 工作区 | **节点密度** | 舒适 / 紧凑（全局紧凑模式） | 舒适 | `renderData.expanded` + 注册表默认折叠态 |
| 节点添加 | **左侧节点面板** | 开 / 关（搜索 + 分类 + 拖拽源） | 开 | 复用 `NodePanel` 数据源改造为侧栏形态（含拖拽手柄） |
| 节点添加 | **工具栏「添加节点」按钮** | 开 / 关 | 开 | 现有 `AddNode`，随工具栏位置设置联动 |
| 节点添加 | 端口「+」创建 | 开 / 关 | 开 | 现有 `use-port-click` |
| 节点添加 | 右键画布菜单 | 开 / 关 | 开 | 现有 context-menu 插件 |
| 节点添加 | 拖线创建 | 开 / 关 | 开 | 现有 `onDragLineEnd` + `LineAddButton` |

说明：节点图标体系（24px 线性 SVG + 六类分类色芯片，注册表单源）已定稿，不再作为决策项。

## 6. 规范与契约影响评估

| 项 | 契约影响 | 依据 |
|---|---|---|
| 方案一全部内容、方案四大部分、图标/主题/紧凑/分组折叠/组描述 | 无（纯 UI / `renderData` 展示态 + localStorage + CSS 变量，DSL 不变） | n8n「结构入工作流、折叠态入浏览器」口径 |
| 方案二：行号沟槽、绿勾、停靠面板、每卡微运行 | 无（前端呈现 + 现有单节点试运行 API） | — |

| 节点禁用（各方案共提及） | **有**：disabled 入 DSL 且执行器跳过 → 契约提案 | 同上 |
| 方案三：线性链约束 | **有**：布局语义大改（fixed-layout 引入或约束层）+ DSL 布局兼容 → 单独立项 | P-04 无损演进 |
| 子工作流封装 / Snippet 复用库 | **有**：新节点类型 + 作用域语义 → 单独立项 | 同上 |
| 图标体系、LightCanvas 色板收敛 | 无（纯前端展示层，不进后端 node-catalog） | P-01/P-05 |

## 7. 分期与验收（以推荐组合为准；选定其他方案后重排）

| 期 | 内容 | 验收 |
|---|---|---|
| **P0 视觉快赢** | 图标体系替换（注册表单源 + LightCanvas 收敛）；工具栏三段重组 + 溢出菜单；选择浮层 i18n 修复 | 类型检查、lint、e2e `replay.spec.ts`；全部节点类型图标/分类色比对；LightCanvas 无独立色板 |
| **P1 体验主干** | 主题 token 化 + 深色模式 + 齿轮设置；节点副标题/状态/悬停操作/菜单增强/紧凑模式；分组折叠 + 描述 + 嵌套；选区浮动工具条增强（对齐选区）；快捷键帮助弹窗 | 深/浅双主题全组件走查；偏好持久化回归；画布 DSL 快照不变 |
| **P2 效率进阶** | 添加节点面板搜索/分类/收藏（方案二指令面板形态）；底部停靠「运行日志/错误列表」；全局便签面板；命令面板雏形 | 面板搜索命中全部节点类型；停靠面板与现有运行历史打通 |
| **P3 契约类（另行提案）** | 调试三件套（断点/单步/变量监视，执行器语义）；节点禁用；子工作流封装；简模式（方案三） | 按 `specs/changes` 流程，含后端校验链与回归测试 |

测试口径遵循 P-06：分列「类型检查 / lint / e2e / 双主题走查」结果，不以构建成功代替；本提案不含任何数据迁移。
